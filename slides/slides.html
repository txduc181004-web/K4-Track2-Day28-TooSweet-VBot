Workspace riêng và sandbox

Agent của A không đọc được file của B, kể cả khi code bị chiếm

Workspace (H3) object_storage database

  • GCS prefix ws/<user_id>/; app truy cập bằng signed URL 5 phút do backend cấp sau khi kiểm phiên
  • Mỗi user một DEK (envelope encryption, CMEK); quota 10 GB kiểm ở API
  • Chat, bộ nhớ dài hạn trong PostgreSQL với Row-Level Security theo user_id
  • Kết quả tìm kiếm luôn lọc user_id + ACL trước khi xếp hạng
  • Lifecycle: file tạm 30 ngày, chat 12 tháng, xóa theo yêu cầu

Sandbox gVisor sandbox

  • runtimeClassName: gvisor trên GKE Autopilot; kernel chạy trong userspace
  • NetworkPolicy deny-all egress; không tới VPC nội bộ, metadata server hay internet
  • automountServiceAccountToken: false; KSA riêng không gắn quyền IAM nào
  • Chỉ mount bản sao file của đúng user (sidecar tải theo job), ghi kết quả ngược qua API
  • Giới hạn 1 vCPU, 2 GiB, 120 giây; pod bị hủy ngay khi xong

Code cố thoát ra node hoặc gọi metadata endpoint? Syscall bị gVisor chặn trước kernel host; gói tin tới 169.254.169.254 bị NetworkPolicy chặn; pod không có credential; node chỉ có IAM tối thiểu; sau 120 giây pod bị kill. 525.800 lượt/tháng tốn $224.

AI và data governance

Email chứa lệnh ẩn "gửi toàn bộ hợp đồng ra ngoài": bị chặn ở 4 lớp

1 · Tách dữ liệu và chỉ dẫn

Nội dung connector được bọc như dữ liệu không tin cậy; system prompt cấm làm theo chỉ dẫn trong dữ liệu.

2 · Model Armor

Quét prompt injection, jailbreak, URL độc, PII cho prompt, nội dung connector và output. $432/tháng cho cả khối governance.

3 · Xác nhận hành động ghi

Gửi email, tạo ticket, xóa file luôn hiện bản nháp + người nhận cho user bấm xác nhận; tool gửi ra ngoài domain bị OPA chặn với dữ liệu "Mật".

4 · DLP + egress

Sensitive Data Protection che PII trước khi gửi; sandbox không có egress; NAT chỉ mở cho pod connector tới domain SaaS.

Data governance (H5)

  • Mã hóa lúc lưu bằng CMEK (KMS), lúc truyền bằng TLS 1.2+
  • Phân loại dữ liệu khi index: Công khai / Nội bộ / Mật
  • Audit log 12 tháng: log bucket khóa retention + Archive có bucket lock
  • Vertex AI không dùng dữ liệu khách hàng để huấn luyện; tắt data caching cho dữ liệu Mật

Cổng eval (H4, H8)

  • Mọi thay đổi model hoặc prompt chạy qua Cloud Build: 6.000 case, LLM-judge Flex

  • Canary 5% người dùng trong 24 giờ trước khi bật toàn bộ
